# AttendX Test Scripts

## Project Description
This repository contains automation test script examples
for the AttendX student attendance application.

## Test Scripts

1. login_test.py
   - Checks that the test username and password are not empty.

2. attendance_test.py
   - Checks the student ID and attendance status.

## Technology
- Python
- Git
- GitHub
- Visual Studio Code

To demonstrate version control, commits, pushing,
